## 🖥️ Projects

### [Scientific Work: Quantization of Diffusion Models](https://github.com/YaguarEgor/scientific_work)

**Description**: My scientific course work focused on developing a new quantization algorithm for diffusion models. The current approach is based on Residual Vector Quantization with modifications such as orthogonal transformations and layer-wise quantization budgets. The project includes comparisons with scalar baselines, vector quantization methods and VQ-DM.
